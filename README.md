# 🌤️ Weather App

A responsive and user-friendly Weather App developed as part of the **Cognetix Technology Full Stack Developer Internship**.

The application uses the **OpenWeather API** to fetch real-time weather information for cities around the world. Users can search for a city and view its current temperature, weather condition, humidity, wind speed, and weather icon.

---

## 🚀 Live Features

- 🔍 Search weather by city name
- 🌡️ Display current temperature
- 🌤️ Display current weather condition
- 💧 Display humidity
- 💨 Display wind speed
- 🌎 Display city and country
- 🖼️ Dynamic weather icons
- 🌡️ Celsius and Fahrenheit temperature conversion
- ❌ User-friendly error messages
- ⏳ Loading state while fetching weather data
- 📱 Responsive design for desktop and mobile devices
- 🔐 API key protected from GitHub using `.gitignore`
- ⚡ Real-time weather data using Fetch API
